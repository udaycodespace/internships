# Assignment 02 · Data Extraction from Mixed List

## Objective

Develop a Python program to extract and process data from a mixed list containing different Python data structures such as lists, tuples, and dictionaries.

The assignment focuses on identifying data types, extracting values, flattening nested data, and performing simple numerical operations.

---

## Given Data

```python
l = [
    [1, 2, 3, 4, 5, 6],
    (1, 2, 3, 4, 5, 6),
    (3, 4, 5, 66, 78, 5),
    {
        "k1": "Hello",
        "k2": "how",
        "k3": "are",
        "k4": "you"
    }
]
```

---

## Tasks

### Task 1

Extract all elements from the list object.

---

### Task 2

Extract the dictionary from the mixed list.

---

### Task 3

Extract all tuple objects from the mixed list.

---

### Task 4

Flatten the list and tuple objects into a single list containing only numerical values.

---

### Task 5

Calculate the sum of all numerical values.

---

### Task 6

Filter and display only the odd numbers from the numerical data.

---

## Expected Learning Outcomes

- Working with Python lists
- Tuple manipulation
- Dictionary extraction
- Type checking using `isinstance()`
- List comprehensions
- Looping and data flattening
- Basic filtering and aggregation
