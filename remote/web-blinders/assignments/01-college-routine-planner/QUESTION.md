## Objective

Develop a time-based routine planner using Python's `if-elif-else` conditional statements.

Based on the user's wake-up time, the program should recommend an appropriate activity, such as continuing to sleep, getting ready for college, attending classes, or preparing for internship activities.

## Requirements

- Accept wake-up time in `H.MM` format.
- Convert the entered time into total minutes.
- Use an `if-elif-else` ladder.
- Display an appropriate routine based on the given time.

## Expected Input

```text
Enter wake-up time (e.g. 4.30, 7.00, 9.15): 6.45
```

## Expected Output

```text
06.30–07.30 Good Morning! Do your activities and get ready for college.
```

## Concepts Covered

- User Input
- Type Conversion
- Time Calculations
- Conditional Statements
- Decision Making

## Submission

Implement the solution in **Python** using a Jupyter Notebook (`solution.ipynb`).
