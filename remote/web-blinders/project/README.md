# User Behavior Analysis using Exploratory Data Analysis (EDA)

> **Track:** AI/ML SIT2025
>
> **Organization:** The Web Blinders
>
> **Project:** User Behavior Analysis

This repository contains an Exploratory Data Analysis (EDA) project completed as part of the **AI/ML Track** at **The Web Blinders**.

The objective of this project is to analyze a user behavior dataset, perform data cleaning and exploration, identify patterns and trends, and generate meaningful insights through visualizations.

## Project Structure

| Path | Description |
|------|-------------|
| 📁 `datasets/user_behavior_dataset.csv` | Dataset used for analysis |
| 📓 `notebooks/01-initial-exploration.ipynb` | Initial exploration, experimentation, and rough analysis |
| 📓 `notebooks/02-exploratory-data-analysis.ipynb` | Final EDA notebook with cleaned workflow, visualizations, and insights |
