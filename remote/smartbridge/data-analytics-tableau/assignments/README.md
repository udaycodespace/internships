# Data Analytics with Tableau Assignments

This repository contains my assignment submissions completed as part of the **Data Analytics with Tableau** course during the **SmartInternz APSCHE Virtual Internship**.

The assignments focus on analyzing supermarket sales data using Tableau, progressing from fundamental visualizations to advanced analytics and interactive dashboard development.
